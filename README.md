# EclipseTone Productions

Official website for [eclipsetone.com](https://eclipsetone.com) — recording, arranging, mixing, mastering, vocal production, and sound for motion. Based in Montréal, Québec.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
